🎯 세 가지 내보내기 대상

AutoFlowCut은 완성된 프로젝트를 세 가지 편집 프로그램으로 내보냅니다. 내보내기 버튼 옆 ▾ 메뉴 또는 내보내기 모달 위쪽의 탭에서 대상을 고르세요.

✂️ CapCut

  • 결과물 — CapCut 프로젝트 폴더
  • 저장 위치 — CapCut 프로젝트 폴더 (앱이 자동 감지)
  • 사용자명 필요 — 예 (경로에 포함)

🎬 Premiere Pro

  • 결과물 — .prproj 파일
  • 저장 위치 — 작업 폴더 안의 프로젝트 폴더
  • 사용자명 필요 — 아니요

📝 Vrew

  • 결과물 — .vrew 파일
  • 저장 위치 — 작업 폴더 안의 프로젝트 폴더
  • 사용자명 필요 — 아니요

ℹ️ 한 번의 내보내기에는 대상 하나만 기록됩니다 — 세 형식을 한꺼번에 내보내는 기능은 없습니다. 다른 형식도 필요하면 대상을 다시 골라 한 번 더 내보내세요.

💡 작업 폴더는 설정에서 지정한 폴더로, 생성된 이미지·영상·오디오가 저장되는 곳입니다. Premiere와 Vrew는 프로젝트 파일을 이 미디어 옆(작업 폴더/프로젝트명/)에 저장하므로 별도 경로 입력이 필요 없습니다.

🚀 빠른 시작 (4단계)

1

내보내기 대상 선택

"📦 내보내기" 버튼의 ▾ 메뉴에서 ✂️ CapCut · 🎬 Premiere · 📝 Vrew 중 하나를 선택합니다. 버튼 본체는 마지막에 고른 대상을 기억하며, 모달이 열린 뒤에도 위쪽 탭으로 바꿀 수 있습니다.

2

저장 위치와 옵션 확인

CapCut은 프로젝트 폴더 경로와 프로젝트 번호를, Premiere·Vrew는 저장될 파일 경로를 모달에서 보여줍니다. 이미지 스케일 · 켄 번스 · 자막 옵션은 세 대상 공통입니다.

3

📦 내보내기 클릭

앱이 프로젝트 파일을 디스크에 직접 기록합니다. 압축을 풀거나 폴더를 복사할 필요가 없습니다.

4

에디터에서 열기

내보내기가 끝나면 앱이 해당 에디터를 자동으로 실행합니다. 실행에 실패하면 알림이 뜨며, 저장된 파일을 직접 열면 됩니다.

✂️ CapCut 내보내기

모달에서 ✂️ CapCut 탭을 고르면 앱이 시스템 사용자명과 CapCut 프로젝트 폴더 경로를 자동으로 감지하고, 비어 있는 다음 프로젝트 번호를 채워 넣습니다. 경로가 감지되지 않거나 다른 위치에 넣고 싶다면 프리셋 버튼(CapCut / CapCut Pro / Documents / 직접 입력)으로 바꿀 수 있습니다.

취소 📦 내보내기

무엇이 어디에 쓰이나요

내보내기를 누르면 앱이 CapCut 프로젝트 폴더에 직접 프로젝트 파일을 기록합니다. 이미지·영상·오디오·자막(SRT)은 복사하지 않고, 작업 폴더에 있는 원본을 절대 경로로 참조합니다. 

📁 com.lveditor.draft/0131/     # CapCut 프로젝트 폴더 (여기에 기록)
├── 📄 draft_info.json          # CapCut 프로젝트 데이터
├── 📄 draft_meta_info.json     # 프로젝트 메타데이터
└── 📄 draft_agency_info.json   # CapCut이 요구하는 기본 파일

📁 작업 폴더/프로젝트명/          # 미디어는 여기 그대로 (절대 경로로 참조)
├── 🖼️ scene_001.png
├── 🎞️ ...
└── 📄 프로젝트명_subtitle_ko.srt  # 자막 포함 시

⚠️ 내보내기 이후 작업 폴더나 그 안의 프로젝트 폴더를 옮기거나 이름을 바꾸거나 지우면 CapCut에서 미디어가 사라진 것으로 표시됩니다. 기록이 끝나면 앱이 CapCut을 자동으로 실행합니다.

👤 시스템 사용자명 찾기

CapCut 프로젝트 폴더 경로에는 시스템 사용자명이 들어갑니다. 보통은 앱이 자동으로 감지하지만, 경로를 직접 입력하거나 확인해야 할 때 아래 방법으로 찾으세요. Premiere와 Vrew는 작업 폴더에 저장되므로 사용자명이 필요 없습니다.

🍎 macOS
  1. 터미널 앱 실행 (Spotlight: Cmd + Space → "터미널")
  2. whoami 입력 후 Enter
  3. 표시되는 이름이 사용자명입니다
🪟 Windows
  1. 명령 프롬프트 실행 (Win + R → "cmd")
  2. whoami 입력 후 Enter
  3. 컴퓨터명\사용자명 형식으로 표시됨 (사용자명만 사용)

📁 CapCut 프로젝트 폴더 경로

🍎 macOS 
~/Movies/CapCut/User Data/Projects/com.lveditor.draft/

💡 Finder에서 Cmd + Shift + G 누르고 경로 붙여넣기

🪟 Windows

CapCut (기본)

C:\Users\[사용자명]\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft\

CapCut Pro

C:\Users\[사용자명]\AppData\Local\CapCutPro\User Data\Projects\com.lveditor.draft\

Documents

C:\Users\[사용자명]\Documents\CapCut\Projects\

💡 파일 탐색기 주소창에 경로 직접 입력 또는 Win + E

🎬 Premiere Pro 내보내기

모달에서 🎬 Premiere 탭을 고르면 저장될 .prproj 파일 경로가 그대로 표시됩니다. 경로를 입력하거나 사용자명을 찾을 필요가 없습니다 — 미디어가 있는 작업 폴더의 프로젝트 폴더에 그대로 저장됩니다. 

📁 작업 폴더/프로젝트명/
├── 📄 프로젝트명.prproj   # Premiere Pro 프로젝트 (gzip 압축된 XML)
├── 🖼️ scene_001.png      # 미디어는 원래 자리 그대로
└── 🎞️ ...

에디터에서 열기

  • 내보내기가 끝나면 앱이 .prproj를 Premiere Pro로 자동 실행합니다
  • 실행에 실패하면 알림이 뜹니다 — Finder/파일 탐색기에서 .prproj를 더블클릭하세요

알아둘 점

  • 자막은 프로젝트 안에 포함됩니다 — CapCut처럼 별도 SRT 파일을 만들지 않습니다
  • 파일명이 프로젝트명.prproj로 고정이라, 같은 이름의 파일이 이미 있으면 덮어쓸지 묻습니다. 덮어쓰면 Premiere에서 손본 내용은 사라집니다
  • 작업 폴더가 설정되어 있지 않으면 내보내기 버튼이 비활성화됩니다 — 설정에서 작업 폴더를 먼저 지정하세요

📝 Vrew 내보내기

모달에서 📝 Vrew 탭을 고르면 저장될 .vrew 파일 경로가 표시됩니다. Premiere와 마찬가지로 경로 입력이나 사용자명이 필요 없습니다. .vrew 파일에는 프로젝트 데이터와 미디어가 함께 담깁니다. 

📁 작업 폴더/프로젝트명/
├── 📄 프로젝트명.vrew    # Vrew 프로젝트 (미디어 포함 패키지)
├── 🖼️ scene_001.png
└── 🎞️ ...

에디터에서 열기

  • 내보내기가 끝나면 앱이 .vrew를 Vrew로 자동 실행합니다
  • 실행에 실패하면 알림이 뜹니다 — 저장된 .vrew를 직접 열면 됩니다

알아둘 점

  • 같은 이름의 .vrew가 이미 있으면 덮어쓸지 묻습니다
  • Vrew가 아직 지원하지 않는 항목은 건너뛰고, 몇 개를 건너뛰었는지 알림으로 알려줍니다
  • 스토리 모드의 나레이션 세그먼트는 .vrew에 배치되지 않습니다 (CapCut · Premiere 전용)
  • MCP 서버로 자동화할 수 있는 내보내기는 CapCut과 Premiere뿐입니다 — Vrew는 앱에서 직접 내보내세요

⚙️ 공통 내보내기 옵션

아래 옵션은 세 대상 모두에 똑같이 적용되며, 마지막으로 고른 값이 저장됩니다.

🔍 이미지 스케일

  • Fill — 화면을 가득 채웁니다 (화면비가 다르면 가장자리가 잘릴 수 있음)
  • Fit — 이미지 전체가 보입니다 (화면비가 다르면 여백이 생길 수 있음)
  • None — 원본 크기(100%) 그대로 사용합니다

🎬 켄 번스 효과

  • 정지 이미지에 자동으로 줌·팬 애니메이션을 넣습니다
  • 모드 — 랜덤(매 주기 무작위) 또는 패턴(줌 인·줌 아웃·팬 중에서 선택)
  • 주기 — 애니메이션이 바뀌는 간격(초)
  • 스케일 — 줌 범위(%). 100~150% 사이를 권장합니다

💬 자막 포함

  • 자막이 있는 프로젝트에서만 표시되는 옵션입니다
  • CapCut은 작업 폴더에 SRT 파일을 만들어 프로젝트에서 참조하고, Premiere는 프로젝트 파일 안에 자막을 포함합니다

⬇️ 에디터가 설치되어 있지 않다면

내보내기를 누르면 앱이 대상 에디터가 설치되어 있는지 먼저 확인합니다. 설치되어 있지 않으면 내보내기를 멈추고 다운로드 페이지를 열지 물어봅니다. 확인을 누르면 기본 브라우저에서 아래 주소가 열립니다.

  • ✂️ CapCut — https://www.capcut.com/download (Microsoft Store 버전 앱에서는 스토어 페이지가 열립니다)
  • 🎬 Premiere Pro — https://www.adobe.com/products/premiere.html
  • 📝 Vrew — https://vrew.voyagerx.com/

💡 CapCut 경로를 직접 입력으로 지정한 경우에는 설치 확인을 건너뜁니다. Microsoft Store 버전 앱에서는 Premiere·Vrew의 다운로드 주소를 링크로 열지 않고 안내 문구로 보여줍니다.

🔧 문제 해결

프로젝트가 CapCut에 나타나지 않아요

  • CapCut을 완전히 종료 후 다시 시작해보세요
  • 모달에 표시된 경로가 실제로 쓰고 있는 CapCut 프로젝트 폴더(com.lveditor.draft)인지 확인하세요
  • 프로젝트 폴더 이름에 특수문자가 없는지 확인하세요

미디어 파일이 누락되었다고 나와요 (CapCut)

  • CapCut 프로젝트는 미디어를 복사하지 않고 작업 폴더의 원본을 절대 경로로 참조합니다
  • 내보낸 뒤 작업 폴더(또는 그 안의 프로젝트 폴더)를 옮기거나 이름을 바꾸거나 지우지 마세요
  • 이미 옮겼다면 원래 자리로 되돌리거나, 작업 폴더를 다시 지정하고 내보내기를 한 번 더 실행하세요

어떤 경로를 선택해야 하나요? (CapCut)

  • AutoFlowCut 앱에서 프리셋 버튼(CapCut / CapCut Pro / Documents)을 바꿔가며 확인하세요
  • CapCut 프로젝트 폴더를 직접 열어서 기존 프로젝트가 있는 경로를 확인하세요
  • 일반적으로 CapCut이 기본 경로입니다

AppData 폴더가 보이지 않아요 (Windows)

  • 파일 탐색기 > 보기 > 숨긴 항목 체크
  • 또는 주소창에 %localappdata% 직접 입력

내보내기 버튼이 눌리지 않아요 (Premiere · Vrew)

  • 작업 폴더가 지정되어 있지 않으면 두 대상의 내보내기 버튼은 비활성 상태입니다
  • 설정에서 작업 폴더를 지정한 뒤 다시 시도하세요

덮어쓸지 묻는 창이 떠요 (Premiere · Vrew)

  • 프로젝트 파일명이 프로젝트명으로 고정이라, 같은 파일이 이미 있으면 덮어쓰기를 확인합니다
  • Premiere에서 손본 내용을 지키려면 취소하고, 기존 .prproj의 이름을 바꾼 뒤 다시 내보내세요
  • CapCut은 비어 있는 다음 번호를 쓰기 때문에 덮어쓰기 확인이 없습니다

에디터가 자동으로 열리지 않아요

  • 파일은 이미 저장된 상태입니다 — 실패 알림이 떠도 내보내기 자체는 끝났습니다
  • 모달에 표시됐던 경로로 가서 .prproj 또는 .vrew를 직접 여세요

"지원하지 않는 항목을 건너뛰었습니다" 알림이 떠요 (Vrew)

  • Vrew 내보내기가 아직 지원하지 않는 항목은 건너뛰고, 건너뛴 개수를 알려줍니다
  • 프로젝트 자체는 정상적으로 저장됩니다 — 해당 요소만 Vrew에서 다시 넣으면 됩니다
  • 모든 요소가 그대로 필요하다면 CapCut이나 Premiere로 내보내세요
