눈박자 (Snowbeat) 개인정보 처리방침

최종 갱신: 2026년 9월 1일 · English

요약

눈박자에는 계정이 없습니다. 로그인, 회원가입, 이메일 수집을 하지 않습니다. 이름·전화번호·주소·결제정보를 묻지 않으며, 게임 설정과 기록은 기기 안에만 저장됩니다. 기기 밖으로 나가는 것은 멀티플레이 위치 정보와 광고 두 가지뿐입니다.

1. 기기에만 저장되는 것 (전송되지 않음)

아래 항목은 기기의 로컬 저장소에만 보관되며 서버로 전송되지 않습니다. 앱을 삭제하면 함께 사라집니다.

  • 게임 설정: 음악·효과음 볼륨, 카메라 거리, 시간대, 화질, 언어, 조작 반전
  • 개인 기록: 가장 멀리 간 주행 3개의 거리·날짜·넘어진 좌표
  • 표시 이름: 멀티플레이에서 사용할 별명 (입력하지 않아도 게임은 동작합니다)
  • 리듬 설정: 선택한 곡, 탭 지연 보정값
  • 가져온 곡: 사용자가 직접 선택한 MIDI 파일

2. 멀티플레이에서 전송되는 것

주행을 시작하면 다른 플레이어를 화면에 표시하기 위해 실시간 위치를 주고받습니다.

  • 전송 대상: wss://flowline.games.bu.app — 이 앱이 파생된 원작 Flowline 프로젝트가 운영하는 서버이며, 터치젠이 운영하지 않는 제3자 서버입니다. 원작자의 사용 허락을 받았습니다.
  • 보내는 것: 표시 이름, 색 번호, 게임 내 좌표(x·y·z)·방향·자세·속도·진행 거리. 약 0.075초마다 갱신됩니다.
  • 보내지 않는 것: 이메일, 전화번호, 연락처, 사진, 실제 위치(GPS), 기기 식별자, 광고 ID, 결제정보.
  • 보관: 이 데이터는 함께 접속한 플레이어에게 실시간으로 보여주기 위한 것이며, 터치젠은 이를 저장하거나 다른 목적으로 사용하지 않습니다.

표시 이름은 사용자가 직접 정합니다. 실명이나 신원을 알아볼 수 있는 정보를 사용하지 않기를 권합니다. 이름은 다른 플레이어의 화면에 표시됩니다.

3. 광고

이 앱은 Google AdMob 광고를 표시합니다. 넘어졌을 때 “광고를 보고 이어가기”를 묻는 보상형 광고이며, 거절해도 게임 이용에 아무런 제약이 없습니다.

  • Google은 광고 제공·측정 및 부정클릭 방지를 위해 광고 ID, 기기 정보, IP 주소 등을 수집할 수 있습니다. 이는 Google의 정책에 따르며, 터치젠은 해당 데이터를 받지 않습니다.
  • Google의 데이터 처리 내용: https://policies.google.com/technologies/ads
  • 광고 ID 재설정 및 맞춤 광고 사용 중지는 안드로이드 설정 → 개인정보 보호 → 광고에서 직접 하실 수 있습니다.

4. 어린이

이 앱은 어린이를 대상으로 제작되지 않았으며, 어린이의 개인정보를 알면서 수집하지 않습니다.

5. 삭제

기기에 저장된 모든 내용은 앱을 삭제하면 함께 제거됩니다. 계정이 없으므로 별도의 탈퇴 절차가 없습니다.

6. 변경

본 방침이 변경되면 이 페이지 상단의 최종 갱신일을 함께 수정합니다.
